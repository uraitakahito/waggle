## waggle とは

waggle が答えるのは **「どの URL を撮るか」** の一点だけです。呼び出し元が
クロールを頼むと、waggle は種を決め（明示された一覧か、Postgres の
`capture_targets` テーブルの `enabled` な行）、辿る範囲を判断し、1 段ずつ
Windmill の flow に渡します。実際に投げるのはその flow です。

名前はミツバチの[尻振りダンス](https://en.wikipedia.org/wiki/Waggle_dance)から。
仲間に蜜のありかを伝える踊りです。

## waggle の責務ではないこと

ブラウザの操作、スクリーンショットの撮影、WACZ の生成、S3 への保存 — これらは
**すべて BrowserHive の責務**です。BrowserHive の docs は web に公開されていないので、
BrowserHive のチェックアウトで `pnpm run docs:local` を実行して読んでください。

**投げることも、もう waggle の仕事ではありません。**
[forage](https://github.com/uraitakahito/forage) の Windmill flow が gRPC の
チャンネルを持っていて、waggle の設定に BrowserHive の在り処は 1 つも入って
いません。flow が報告する 1 段には、ページごとの `taskId` が載っています。waggle は
そこからアーカイブを生んだものを[アーカイブ台帳](/waggle/ja/archive-ledger/)に
記録します。取りこぼしは後から `pnpm run fga:reconcile` が bucket の結果 manifest を
走査して拾います。

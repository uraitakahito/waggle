## waggle とは

waggle が答えるのは **「どの URL を撮るか」** の一点だけです。Postgres の
`urls` テーブルから `enabled` な行を読み、1 行につき 1 回
`POST /v1/captures` を BrowserHive
へ並列に投げます。

名前はミツバチの[尻振りダンス](https://en.wikipedia.org/wiki/Waggle_dance)から。
仲間に蜜のありかを伝える踊りです。

## waggle の責務ではないこと

ブラウザの操作、スクリーンショットの撮影、WACZ の生成、S3 への保存 — これらは
**すべて BrowserHive の責務**です。waggle が肩代わりしないという話ではなく、
そもそも担当が分かれています。したがってこのサイトでも説明しません。
「どう撮るか」に関することは
BrowserHive のドキュメントにあります。あちらの docs は web に公開されていないので、
BrowserHive のチェックアウトで `pnpm run docs:local` を実行して読んでください。

やり取りは **投げっぱなし (fire-and-forget)** です。BrowserHive は `202` と
`taskId` を即座に返し、実際のキャプチャはワーカープール上で非同期に走ります。
waggle は受理されたかどうかだけを記録して終了します。タスクの完了追跡は
未実装で (ロードマップの Stage 1)、結果は BrowserHive のログと成果物ストアに
現れます。

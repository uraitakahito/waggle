## waggle とは

waggle が答えるのは **「どの URL を撮るか」** の一点だけです。Postgres の
`urls` テーブルから `enabled` な行を読み、1 行につき 1 回
`POST /v1/captures` を [BrowserHive](https://uraitakahito.github.io/browserhive/ja/)
へ並列に投げます。

名前はミツバチの[尻振りダンス](https://en.wikipedia.org/wiki/Waggle_dance)から。
仲間に蜜のありかを伝える踊りです。

## waggle がやらないこと

ブラウザを操作しません。スクリーンショットも撮らず、WACZ も作らず、S3 にも
書きません。**それは全部 BrowserHive の仕事**で、このサイトでは説明しません。
「どう撮るか」に関することは
[BrowserHive のドキュメント](https://uraitakahito.github.io/browserhive/ja/)にあります。

やり取りは **投げっぱなし (fire-and-forget)** です。BrowserHive は `202` と
`taskId` を即座に返し、実際のキャプチャはワーカープール上で非同期に走ります。
waggle は受理されたかどうかだけを記録して終了します。タスクの完了追跡は
未実装で (ロードマップの Stage 1)、結果は BrowserHive のログと成果物ストアに
現れます。
